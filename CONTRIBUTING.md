# Contributing

Thanks for helping keep this guide accurate and useful.

## Good contributions

Useful pull requests include:

- correcting outdated setup steps or menu paths;
- updating provider, addon, or public-instance information with a source;
- improving troubleshooting steps based on reproducible behavior;
- fixing broken links or unclear wording;
- adding a recommendation only when it fills a real gap in the current lean setup.

Please avoid turning the guide into a giant addon list. The project intentionally favors a small, maintainable stack over duplicate sources and unnecessary complexity.

## Before opening a pull request

1. Check the current official documentation where possible.
2. Test the change against the relevant client or service if practical.
3. Keep client-specific instructions in `STREMIO.md` or `NUVIO.md`.
4. Put addon recommendations in `ADDONS.md` and problem-solving notes in `TROUBLESHOOTING.md`.
5. Add or update a reference in `SOURCES.md` when the change depends on time-sensitive behavior, pricing, limits, or service support.

## Pull requests

Keep each pull request focused on one logical change and explain what was changed and why. Screenshots or source links are welcome when they help verify behavior.

This repository is a community guide and is not affiliated with Stremio, Nuvio, AIOStreams, TorBox, Real-Debrid, or the addon developers.
